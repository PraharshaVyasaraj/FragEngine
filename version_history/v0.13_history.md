**Commit:** `ada2cf9` | **Tag:** `v0.13`
- **Telemetry Engine** (`backend/telemetry.py`): Background thread samples CPU %, RAM MB, thread count, and context switches every 500ms via `psutil`.

## V0.13.2 — ROI Auto-Lock Bug Fix
**Commit:** `f14edf0`
- **Bug**: During calibration, the drawn ROI was only stored as a `calibration-draft` in `popup.js`. If the user skipped clicking "Lock" and went straight to "Start Ingest", the system fell back to hardcoded 1920x1080 default ratios — capturing the wrong screen region.
- **Fix** (`content.js`): ROI now **auto-locks** on `mouseup` — immediately persists to `chrome.storage.local`, sends `calibration-locked` to the background worker, and auto-closes the overlay after 300ms.
- **Fix** (`popup.js`): Side Panel UI reflects auto-locked state instantly (green "ROI AUTO-LOCKED" label, Start button enabled, Lock button disabled).

## V0.13.3 — CSV Export Bug Fix (Root cause present since V0.1)
**Commit:** `f3e6ce0`
- **Bug**: The "Export CSV" button in the Side Panel silently failed on every click from V0.1 through V0.13.2. Root cause: Chrome Manifest V3 side panels cannot trigger file downloads via `encodeURI` + `data:` URI scheme — the browser blocks it silently with no error.
- **Fix** (`popup.js`): Replaced broken approach with `Blob` + `URL.createObjectURL()` + `chrome.downloads.download()`. Fields are now quoted to safely handle commas in player names. Export filename is auto-timestamped (`FragEngine_QL_YYYYMMDD_HHMM.csv`).
- **Fix** (`manifest.json`): Added `"downloads"` permission (was missing — the root blocker).
- **Evidence**: Confirmed via SESSION_0006 QL log analysis (230 entries). Special character injection (`}`, `[`, `)`) and right-edge truncation patterns documented for V0.14 post-processing improvements.
