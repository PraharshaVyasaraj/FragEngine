# FragEngine Release History — V0.16

## Release Overview
**V0.16** introduces high-performance hardware acceleration by targeting Intel Integrated GPU (iGPU) hardware using OpenVINO. It also resolves matching edge cases on varying overlay formats using multi-scale and multi-threshold template matching.

---

## ⚡ Key Optimizations & Refactorings

### 1. OpenVINO iGPU Hardware Acceleration
* **Target Latency (30-40ms)**: Configured the execution pathway to leverage OpenVINO GPU compilation targeting the Intel UHD 770 integrated GPU.
* **Auto-Fallback Recovery**: Built a cascading fallback structure (`OpenVINO iGPU` $\rightarrow$ `OpenVINO CPU` $\rightarrow$ `Standard CPU`) to prevent driver or library compilation error crashes.

### 2. Extension State Consolidation
* **Removed Rest Mode**: Discarded `REST` state back-offs, simplifying the logic down to two strict, high-performance sampling intervals:
  - **Normal Mode (500ms)**
  - **Rapid Mode (200ms)**
* **Fight Window Lock**: Transition rules automatically elevate parsing frequency to 200ms instantly when an icon is detected, locking the frequency for a 1.5s window before returning to 500ms Normal mode.

### 3. Multi-Scale & Multi-Threshold Matching Overhaul
* **Scale Tolerance (`[0.9, 1.0, 1.1]`)**: Resizes matching bounds to accommodate varying capture sizes, resolutions, or cropping alignment slips.
* **Contrast Tolerance (`[160, 180, 200]`)**: Evaluates correlations across three binarization values to prevent glowing borders or high-brightness backgrounds from washing out icon silhouettes.
* **Aspect-Ratio Preserved Letterboxing**: Fully preserves icon dimensions by padding borders rather than stretching pixels.
