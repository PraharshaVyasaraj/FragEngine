# Feed Parser V0.1 - Initial Release

## Changes Made
- Established Hybrid Architecture: Chrome Extension frontend capturing `<video>` frames, Local Python Flask server running EasyOCR.
- Implemented Chrome Side Panel UI to keep controls visible alongside the video.
- Created `QL.csv` logging with exact-string match deduplication ("The Wall").
- Polled video feed at 5 FPS (200ms intervals).

## Why / Cause
- To extract real-time kill feed telemetry from YouTube VODs without downloading the videos.
- 5 FPS was chosen because EasyOCR takes ~40ms per frame on CPU, making 20-30 FPS mathematically impossible without queuing.

## Expected Result
- A functional end-to-end pipeline.
- Successful OCR extraction of Layout Type, T1, I1, I2, and T2, appending to CSV in real-time.
